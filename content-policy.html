AI Signal 内容与版权政策

AI Signal 是资讯索引与事件聚合服务，不主张第三方新闻、帖子、论文和图片的版权。版权归原发布者或权利人所有。

公开页面原则上仅展示标题、必要的短摘要、来源、时间和原文链接。完整内容请访问原始来源；不得把本站摘要视为投资、法律或其他专业建议。

来源接入应优先使用官方 RSS、公开 API 或明确允许抓取的页面，并遵守来源服务条款与 robots.txt。付费内容、登录后内容和明确禁止自动化访问的内容不应采集。

权利人可通过 GitHub Issues 提交删除或更正请求，请附上权利证明、相关 URL 和联系方式。核实后将停止后续公开展示。
